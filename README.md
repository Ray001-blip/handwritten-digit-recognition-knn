# Handwritten Digit Recognition using KNN

## Project Overview
A complete Machine Learning project for classifying handwritten digits (0-9) using the Scikit-Learn Digits dataset and K-Nearest Neighbors (KNN) algorithm.

## Features
- OOP implementation with `DigitRecognizer` class
- Data visualization using Matplotlib
- KNN with multiple K values and accuracy comparison
- Confusion matrix
- Average digit visualization using NumPy

## Results
- **Best Accuracy**: 98.89% (K=7)

## Setup
```bash
pip install -r requirements.txt
python digit_recognizer.py
```
